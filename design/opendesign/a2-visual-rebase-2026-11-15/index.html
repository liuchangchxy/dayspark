DaySpark「灵光」· A″ 核心交互模型 · 生产级 UI 原型

视觉语言沿用已验收的 Direction C「安静纸墨」。本套原型覆盖 17 个手机状态（390×844，含状态栏 / 安全区 / 键盘态 / 深色）与 3 个桌面屏（1440×900），把 A″ 的「长什么样、怎么排、控件放哪」全部定死，供 Flutter 实现直接对照。逐条拍板与关键尺寸见 design-notes.md。

FLOW一条任务的连续流：捕获 → 未安排 → 安排 → 执行 → 完成

示例：早上在「今天」捕获「整理周会纪要」→ 进未安排 → 切「待办·按日期」安排到 11/17 14:00–15:00 → 11/17 时间轴出现计划执行块 → 勾选完成。同一 Todo 若同时有截止（15:00）与计划（14:00–15:00），全 App 任何列表/时间轴只显示一次——计划执行为主行，截止是次级元信息。
