## (d) What I could not verify

1. **Shared browseDate (rule 2).** The "same variable" between 待办·按日期 and 日历 is a state relation, not visible in static HTML. Separately, 06 (11/15), 07 (11/17) and 12/13/13b (11/15) are consistent, and 07's `截止 10/26` is not rewritten by browsing — but I cannot prove one shared variable from the files alone.
2. **Picker write behaviour.** "Select a day writes browseDate and closes the sheet", "点「今天」= 跳回今天", and `回到今天` are only labels/affordances in the static prototype; the click behaviour is not executable. In particular, the date-strip's `今天` text (`screens-todo.html:345`) is not a separate clickable target from the strip that opens the picker, so the "click 今天 to jump back" half of `design-notes.md:68` is not demonstrable.
3. **The prefilled composer from the calendar slot.** Board 14 shows the slot sheet with `18:00–19:00`, but the composer it opens with start/end prefilled (`design-notes.md:93`, the only path allowed to inherit the time) is not rendered anywhere. I could verify the slot sheet's three action texts, not the resulting composer.
4. **The expanded Today 未安排 group.** 01/DARK are collapsed; 03 shows the 3-row preview + `还有 7 项 · 展开全部`, but the expanded 7 rows (which would include with-deadline items) are not rendered, so P2-7 is a model-level contradiction rather than a visible duplicate.
5. **The FAB action menu.** `design-notes.md:77` says the month FAB opens the same three actions as board 14; no board renders the FAB menu (`.fab-menu` CSS exists, no markup).
6. **Dark mode outside Today.** Only Today has a DARK board; `design-notes.md:121` says only Today is required, so this is by design, but the other screens' dark behaviour is unverified.
7. **True interactive states on desktop.** Hover, the 150 ms detail slide-in, Esc-to-close, and the `‹ ›` behaviour on the 今天 destination are represented by static markup/notes only.

---

## Bottom line

The rebase preserves the A″ creation/date flow (capture → 未安排; no prefilled allocation from 「安排到这一天」; dedupe; the date picker and all 17+3 states). It does not preserve the A″ deadline/overdue separation: the new Direction C capsule paints past deadlines with the overdue `danger` on 未安排/全部/按日期, while the model reserves that judgement for Today and the desktop board does it correctly. That is the one P1. The rest are a missing mobile `+N`, the collapsed Today preview, the FAB/notes contradiction for week/day, a browsable desktop Today header, a missing date on the 协议 deadline in global lists, the unrendered year mode, a board-08 background mismatch, and the weakened capture `+`.
