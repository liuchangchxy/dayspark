## 1. 方向

**Apple × Linear，纸与墨。**

- 手机约 80% Apple / 20% Linear：大标题、直接操作、底部拇指区、圆形选择态、克制的动效。
- 桌面约 45% Apple / 55% Linear：高密度侧栏、中性选中、主从结构、键盘优先、几乎无阴影。
- 一套品牌贯穿三端：暖纸底、近黑墨色、单一深钴蓝强调、低饱和日历色、语义暖褐/红/绿。
- 视觉层级来自字号、字重、留白、对齐与 1px 分隔线，不来自卡片、色块和阴影。

---

## 2. 诊断：之前为什么像 AI 生成

基于源码构建的 Web UI 与真实截图，而不是旧 Windows 构建：

1. 每个区块都是白卡片 + 阴影 + 大圆角；设置页像后台表单。
2. 主操作用高饱和蓝色实心块，侧栏选中也是蓝底；一屏出现 4–5 处蓝色竞争。
3. 日历事件全部 `primary-soft` 蓝底 + 3px 蓝边；日历色只出现在行尾小圆点。
4. 日期选择整格填蓝；今天/选中态靠大面积色块。
5. 每行一个彩色圆点，既无标签也不承担操作，成为装饰噪声。
6. 字重 650/700/750/800 混用，标题靠加粗而不是尺度；中文标题用负字距。
7. 桌面内容左对齐但宽度不一，1440 下大片空白；侧栏密度低、选中态过重。
8. 小组件是“把卡片缩小”，三尺寸只是行数不同；快捷操作卡片套卡片。
9. 深色是浅色反相，日历色在近黑背景上消失。

## 3. 令牌决议

### 3.1 更少、更硬

| 类别 | 之前 | 现在 |
| --- | --- | --- |
| 圆角 | 6/8/10/14/18/22/999 混用 | 4 / 6 / 8 / 12 / 18；内容里不再用胶囊 |
| 字重 | 400/500/600/650/700/750/800 | 400 / 500 / 600 |
| 灰色 | 多套蓝灰 | bg / surface / ink-1/2/3 / line / line-soft |
| 主色 | `#2457d6` 高饱和蓝 | `#2d4f7c` 深钴蓝 |
| 背景 | `#f2f4f7` 冷灰 | `#f3f3ef` 暖纸 |
| 深色 | `#0e1014` 冷黑 | `#121310` 暖黑 |
| 阴影 | 列表/卡片也带阴影 | 主界面无阴影，只有浮层 |

### 3.2 字体

- 统一系统 UI 栈：Segoe UI Variable Text → Segoe UI → SF Pro Text → PingFang SC → Microsoft YaHei。
- 手机页面标题 26/600；焦点块 20/600；列表 15/400；元信息 12。
- 桌面页头 18/600；列表 15/400；元信息 12；日历标签 10.5。
- 中文标题 `letter-spacing: 0`，正文 0；只有 10–12px 小标签使用 `0.03–0.06em`。
- 中文大标题行高 1.35–1.4；正文 1.6；列表 1.45。

### 3.3 日历色

- 个人 `#4f6d8c`、工作 `#6f5d7e`、学习 `#4f7368`、生活 `#9a6248`、玫红 `#8f5a68`、橄榄 `#6b7048`。
- 事件背景 = 日历色 11% 混入 surface（深色 17%）；只保留 2px 日历色左边，不再加全边框。
- 旧 localStorage 中的高饱和色在 `store.js` 载入时迁移；不动数据库。

## 4. 去掉的 slop

| 之前 | 现在 |
| --- | --- |
| 正在进行 = 白卡片 + 彩色左边框 | 无卡片、无底色、无左边框；暖色标签 + 20/600 标题 + 2px 进度线 |
| 主操作 = 实心蓝块 | 蓝色文字 + 加号；一屏只保留一个实心主按钮 |
| 日期选中 = 整格填蓝 | 30dp 圆形填充，格子透明 |
| 每行 = 白底 + 行尾色点 | 透明行 + 1px 分隔线；移除无标签色点 |
| 设置 = 一张张卡片 | 一个 10px 圆角分组，组内 1px 分隔 |
| chip = 胶囊 + 灰底 | 6px 圆角；只读元信息完全去底 |
| 日历事件 = 蓝底蓝边 | 日历色 11% 混底 + 2px 日历色左边，颜色只表达归属 |
| 快捷操作 = 卡片套卡片 | 1px 发丝线切分的操作网格 |
| 桌面选中 = 蓝底 / 蓝 inset | `surface-2` + 600 字重 |
| 桌面侧栏 = 232px 稀疏列表 | 236px / 32px 行高 / 中性选中 |
| 小组件圆角 22 + 阴影 | 18 + 仅 `shadow-1` |
| 每屏 4–5 处蓝 | 每屏 1 处主色 + 少量语义色 |

## 5. Mobile

- 顶栏只保留搜索、设置、新建；移除 “DAYSPARK” kicker，页面主标题由 `dayhead` 承担。
- 今天页从“卡片流”变成“标题 → 现在 → 接下来 → 今天截止 → 逾期 → 未安排 → 已完成”的阅读顺序。
- 现在块用暖色语义而不是色块；进度线 2px。
- 日期条与月历使用圆形选中；选中与今天不靠整格底色。
- 日历周议程：2px 日历色竖线 + 标题 + 元信息；计划项用中性灰。
- 截止带无外框，截止卡片 6px 圆角、`surface-2`。
- 详情：元信息 chip 去底；操作栏固定在底部；全高 sheet 的 body 可滚动。
- 搜索：说明单行，输入框 8px 圆角。
- 设置：10px 分组、50px 行高、主题色 6 个 24dp 圆点。

## 6. Desktop

- 侧栏 236px；行高 32；选中 `surface-2` + 600；品牌 mark 用 ink 而非主色。
- 主栏 54px / 标题 18/600；工具按钮 32px。
- 今天：内容列最大 820 + 右侧 300px rail；栏内左对齐，不强行居中。
- 主从：列表 380；选中行中性底色；详情内容最大 680。
- Today rail 的“安排”默认透明，hover/focus 可见，键盘可达。
- 周视图：日列线 `line`、小时线 `line-soft`；今天数字 24px 圆；截止带是有底、有列线、有暖色点的结构化行。
- 月视图：最小 92px 格高，桌面按窗口高度拉伸填满、不再在底部留大片空白；24px 今天圆、11px 摘要；每格最多 3 行，溢出用 `+N`。
- 设置：188px 分区导航 + 最大 680 内容。
- 命令面板：12px 圆角、1px 边框、`shadow-2`；结果行 6px 圆角。

## 7. Widgets

- 圆角 18；1px 边框；`shadow-1`。
- 小 / 中 / 大分别回答：一个决定、一条可扫读序列、结构与关系。
- 中/大快捷操作改为全幅 1px 发丝线网格，取消灰色 tile 的“卡片套卡片”。
- 日历大尺寸限制 2 条当天日程，避免 316dp 内溢出；中尺寸 3 条。
- 迷你月历 22dp 圆、10.5px 数字；今天圆形填充。
- 时间轴事件块 11% 日历色，深色下提亮。

---

## 8. 深色

- 暖黑背景 `#121310`，surface `#191a17`，不使用纯黑。
- 日历事件背景 17% 日历色；左条用 60% 白色混合提亮。
- 议程竖条在深色下 `brightness(1.45)`，避免低饱和日历色消失。
- 主色切换为 `#8fb0d9`，主色上文字用深色 `#0d141d`。
- 深色下所有分组、选中、hover 都使用独立色值，不做透明度反相。

## 9. Impeccable pass

- 方向 Skill 使用 OpenDesign `frontend-design`：先锁定 Apple × Linear 单一方向，再按真实界面、状态、响应式与自检清单推进；系统字体栈是刻意的 utilitarian 选择，不是缺省偷懒。
- 使用 `impeccable` 的 critique → distill → typeset → layout → polish 顺序做质量复核，不另立视觉方向。
- 运行 `impeccable context` 读取现有 `DESIGN.md` 与实现；加载 `craft-floor.md` 作为质量底线。
- 采用后修正（第一轮）：
  - 移除顶栏 “DAYSPARK” kicker（eyebrow）。
  - 移除“正在进行”块的装饰性左边框。
  - 移除桌面选中行的 2px 蓝色 inset 边。
  - 去掉列表行尾无标签日历色点。
  - 只读元信息 chip 去底、去 48dp 触控外观。
  - 设置/详情圆角从 14 收到 10/12，阴影只留浮层。
- 采用后修正（复核轮，均只动视觉）：
  - 视觉平面：当前时间线 `z-index: 3` 压过事件；事件改为 11% 日历色 + 仅左条，去掉 1px 全边框与小时线重复。
  - 月视图：每格总行数封顶 3 行，超出显示 `+N`；最小格高 92 且桌面按窗口高度拉伸填满；删除统一灰点；月标签去空格（`2026年11月`）。
  - 桌面待办：进入时详情栏不再是空白，改为图标 + 标题 + 一句下一步说明的空状态。
  - 手机详情：sheet 不再停在 `translateY(16px)` 的悬空态；从屏幕顶部开始，状态栏 z-index 50 保持可见。
  - 小组件：大尺寸日历压紧迷你月历与事件行距，两条日程完整显示，并用“还有 1 个”说明溢出；不再从行中间截断。
  - 中文标题：手机页面标题从 28 降到 26，减少 Microsoft YaHei 只有 400/700 时 600 被渲染成粗体的观感。
- 保留的例外：日历事件 2px 左边框。它承担日历归属，不是装饰；颜色在浅色/深色都单独校准。
- 复核中评估后不采用的建议：
  - “今天流按时间重排”：当前顺序已是 15:00 → 18:30 → 19:00，且截止/逾期是独立分区，重排会改变已验收的信息结构。
  - “去掉所有嵌套卡片”：设置分组与月格承载分组语义，保留；仅移除了装饰性卡片与卡片套卡片。
  - 检测器的静态扫描对 JS 渲染页有漏报；最终以浏览器逐屏截图复核为准，不把静态扫描 0 命中当作通过。
- 未安装 `design-handoff`；以本文件 + `IMPLEMENTATION_HANDOFF.md` §10 + `design-review` 作为替代。
- Android exact-head native build: **NOT VERIFIED**（本机不安装/修复 SDK/NDK）。
