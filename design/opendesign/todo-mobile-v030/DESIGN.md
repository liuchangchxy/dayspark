## 0. 适用范围

只覆盖 **待办 tab 内的三个区域**：Todo 主页面、Todo Quick Create、Todo Full Create / Edit。
不改一级导航、不改 Todo/Event 区分、不改 `dueDate`/`TaskAllocation` 语义、不移除任何已有业务能力。
视觉语言绑定仓库既有的 **D Final 冻结视觉契约**，不新建私有控件体系，优先使用 Material 3 既有组件。

## 1. 设计原则（按优先级）

1. **稳定性优先于信息密度。** 页面骨架的槽位数量、顺序、尺寸在任何数据状态下不变。抖动只能来自数据。
2. **语义不可合并。** 「什么时候做」（TaskAllocation）与「最晚什么时候完成」（dueDate）在界面上永远是两个可分别指认的东西。
3. **默认值必须可见。** 任何推断出的默认值都要以文字明示，禁止静默落值。
4. **功能完整，按需呈现。** 能力一个不少，但只在用户需要时出现。
5. **拇指优先。** 高频操作落在单手可达区，点击目标不小于规定尺寸。
6. **安静。** 无渐变、无装饰阴影、无卡片嵌套、无等重元素。用排版与留白建立层级，不用装饰。

## 4. Todo 主页面

### 4.1 结构（自上而下，顺序固定）

```
AppBar           标题「待办」 + 搜索图标 + 创建按钮「＋ 待办」   56dp
─────────────────────────────────────────────
固定槽位 1       视图段：今天 · 未安排 · 全部                    42dp
固定槽位 2       日期带：[全部日期] 周一 … 周日                  52dp
─────────────────────────────────────────────
可滚动内容       粘性分组头 + 扁平待办行列表
─────────────────────────────────────────────
底部导航         今天 · 日历 · 待办                              ≥48dp
```

Safe Area：顶部 `52`，底部 `28`。底部导航固定在 Safe Area 之上。

### 4.2 两个固定槽位（本设计的核心机制）

**槽位 1「视图段」**
- 三个选项，顺序恒为 `今天 / 未安排 / 全部`。
- 使用 Material 3 `SegmentedButton`，容器高 42dp，选中项白底 + 1dp 阴影 + accent 文字。
- 每项右侧显示计数（13sp，`textSecondary`；选中时 accent）。
- **计数可以为 0，但选项不得消失、不得改文案、不得改顺序。**

**槽位 2「日期带」**
- 八个格子：`[全部日期]` + 当周 `周一`~`周日`。
- 使用横向 `GridView`/`Row`，格高 52dp，白底、圆角 8。
- `[全部日期]` 格显示 dow「全部」+ 字形 `∞`，宽度固定 40dp，与七个日期格不同宽。
- 选中态：accent 底 + 白字。
- 今天格：数字用 accent 色（未选中时）。
- 有待办截止的日期：格内显示一个 5dp 圆点，颜色 `deadline`（选中时转白）。
- 周范围基于「今天」所在周，向左/向右滑动可切换周；切换周不改变视图段状态。
- **格子数量恒为 8，不因数据增减。周范围切换只改数字与选中态。**

**两个槽位的行为契约**
- 视图段与日期带是**正交**的两个维度：视图段决定「按什么条件筛选」，日期带决定「限定哪个日期」。
- 交互矩阵：

| | 日期带 = 全部日期 | 日期带 = 具体某天 |
|---|---|---|
| 视图段 = 今天 | 不合法组合，落库前归一化为「全部日期 + 今天」 | 今天视图（默认态） |
| 视图段 = 未安排 | 未安排视图（默认态） | 未安排视图中，截止在该日的排最前 |
| 视图段 = 全部 | 全部视图（默认态） | 全部视图，限定该日 |

- 点 `[全部日期]` 格 → 视图段切到「全部」。
- 点任一日期格 → 视图段切到「今天」并加载该日。
- 视图段三个选项永不被日期带禁用或隐藏。

### 4.3 分组头

- 粘性吸顶，`canvas` 底 + 底部 1px `separator`。
- 内容：分组标题（13sp/700）+ 计数（13sp/600）+ 弹性分隔线 + 右侧动作（可选）。
- 分组定义与顺序：

| 视图 | 分组 |
|---|---|
| 今天 | `已逾期`（仅当今天及以前有逾期时出现）→ `今天 · M月D日 周X` |
| 未安排 | `未安排`（含一条说明徽标「无有效 TaskAllocation」） |
| 全部 | `已逾期` → `今天 · M月D日` → `明天 · M月D日` → 其余有量日期升序 → `未安排` |
| 具体日期 | 该日期标题 + `回到今天` 动作；**今天之前的日期不出现「已逾期」分组之外的逾期提示，今天之后的日期完全没有逾期分组** |

- 逾期分组的标题用 `error` 色。
- 分组头右侧动作：全部视图的「未安排」分组提供 `只看这些` → 切到未安排视图；今天视图提供 `查看全部` → 切到全部视图。

### 4.4 待办行

布局：`[复选框 48dp] [主内容 1fr] [尾部 auto]`，整行最小高 60dp，行间 1px `separator`。

**主内容**
- 标题：15sp/500，`textPrimary`，最多 2 行，超出省略号。
- 元信息行（标题下 5dp）：胶囊与分隔点横向排列，可换行。
  - 胶囊统一高 22dp、圆角 6、字号 13sp/600。
  - 语义与配色（**顺序固定：计划执行 → 截止 → 其他**）：

| 胶囊 | 底色 | 文字 | 出现条件 |
|---|---|---|---|
| 计划执行 | `accentSoft` | `accent` | `计划 HH:mm` 或 `计划 HH:mm – HH:mm` 或 `计划 M/D HH:mm`；有 TaskAllocation 时 |
| 截止 | `deadlineContainer` | `deadline` | `截止 今天` / `截止 明天` / `截止 M/D`；有 dueDate 时 |
| 逾期 | `errorContainer` | `error` | 已过 dueDate 或已过计划时间且未完成；文案 `逾期 N 天` |
| 未安排执行 | 透明 | `textSecondary` | 无有效 TaskAllocation 时；文案 `未安排执行时间` |
| 无截止 | 透明 | `textSecondary` | 无 dueDate 时；文案 `无截止` |
| 重复 | `surfaceVariant` | `textSecondary` | 有 RecurrenceSpec；文案 `每周重复` 等 |
| 未同步 | `errorContainer` | `error` | 本地有未上传改动 |

  - 计划执行与截止**必须分别成囊**，不得合并为单个「时间」胶囊。

**尾部**
- 优先级圆点 8dp：高 `error`、中 `deadline`、低 `textTertiary`。
- 标签色点 8dp（最多 3 个，超出以 `+N` 文字表示）。
- 无文字按钮、无尾箭头。

**交互**
- 点行 → Full Edit。
- 点复选框 → 切换完成态；复选框是 `aria-pressed` 双态，完成时 accent 底 + 白色对勾。
- 长按行 → 上下文菜单（完成 / 安排执行时间 / 移到回收站）。上下文菜单不承担唯一路径。

**已完成行**：标题 `textTertiary` + 删除线；元信息整行 opacity 0.65。

### 4.5 完成状态开关

- 「已完成」不是第四个视图，而是视图段右侧的一个**筛选开关**（36dp）。
- 开启后列表只显示已完成，按完成日期分组；取消某行完成会把它移出列表，开关自动回到未完成。
- 这样视图段槽位数量不变。

### 4.6 空状态

- 空状态是**列表内的一条插槽**，位于分组头之下，占位约一屏的 1/4~1/3，**不得占满整屏**。
- 内容：40dp 线性图标（`separator` 描边）+ 标题 15sp/600 + 一句说明 13sp + 一个 44dp 文字按钮。
- 日期带、视图段、底部导航全部保留可见。
- 文案按视图区分：今天「今天没有待办」；未安排「没有未安排的待办」；具体日期「这一天没有待办」；全部「还没有任何待办」。

## 5. Quick Create

### 5.1 容器

- 底部 Sheet（`DraggableScrollableSheet` 或 `showModalBottomSheet`），圆角顶部 16，底部贴 Safe Area（距底 28dp）。
- 结构：把手（32×4dp）→ 主体 → 底部动作条（顶部 1px 分隔）。
- 背景遮罩 `rgba(23,26,32,.44)`，点遮罩或下拉关闭。
- 主体最大高度 90%；属性区超出时内部滚动，底部动作条常驻可见。

### 5.2 标题输入（绝对视觉中心）

- 26sp/700，字距 -0.015em，`textPrimary`。
- 底部 2dp `accent` 下边框，无其他边框、无背景、无 Card。
- 占位符「要做什么？」用 `textTertiary`。
- 打开即自动聚焦并弹出键盘。
- **标题为空时「保存」按钮禁用**；不得创建无标题待办。

### 5.3 属性条

- 标题输入第一个字符后出现；此前隐藏。
- 五个属性格横向排列，可横向滚动，格最小 64×60dp。
- 每格两行：键（11sp/700，`textTertiary`）+ 值（13sp/600）。
- **顺序固定：`计划执行 / 截止 / 提醒 / 日历 / 更多`**——计划执行在第一位，这是对 `TaskAllocation` 语义优先级的显式表达。
- 已设置的格：accent 描边 + `accentSoft` 底 + accent 文字。未设置的格显示文字「未设置」，不隐藏、不灰掉。
- 日历格即使未设置也显示当前日历名，并标注「已选」。

### 5.4 各属性面板

**计划执行**
- 顶部四个快捷 chip：`现在 / 今晚 20:00 / 明早 09:00 / 本周末`（40dp）。
- 下方字段行：日期、时段、时长、重复（各 48dp）。
- 保存后该待办立即从「未安排」视图移出。

**截止**
- 快捷 chip：`今天 / 明天 / 本周末 / 下周一 / 清除`。
- 月历：7 列，单元格 40dp，今天 accent 描边，选中 accent 底白字，非本月 `textTertiary`。
- **设置截止不自动创建计划执行**，反之亦然。两个入口在 UI 上明确分离。

**提醒**
- 快捷 chip：`准时 / 提前 15 分钟 / 提前 1 小时 / 提前 1 天`。
- 已添加提醒列表：每行 56dp，图标 + 主文案 + 锚点说明（`按计划执行时间` / `按截止时间`）+ 48dp 删除按钮。
- 「＋ 再添加一条提醒」按钮 48dp。支持多条，上限由业务决定，UI 不设限。

**日历**
- 单选列表，每行 48dp：色点 + 日历名 + 「已选」标注。
- 「＋ 新建日历」48dp。
- **当前日历显式标注，禁止使用 `calendars.first.id` 静默落值。**

**更多**
- 通往 Full Create 的入口页，列出全部属性的当前值摘要。
- 点任一行 → Full Create，**标题与已设属性全部带入**。

### 5.5 底部动作条

- 左：辅助说明「回车连续添加」（13sp，`textTertiary`）。
- 右：`取消`（quiet，48dp）+ `保存`（accent 实底，48dp）。
- 回车行为：标题非空 → 保存并清空标题继续输入；标题为空 → 不动作。
- **Quick Create → Full Create 不得丢失已输入标题与已设属性。**

### 5.6 键盘态

- 键盘弹出时 Sheet 整体上移，输入框始终位于键盘上方。
- 底部动作条保持可见，不随键盘隐藏。
- 使用 `viewInsets` + Safe Area，避免输入框被遮挡或按钮被顶出屏幕。

## 6. Full Create / Edit

### 6.1 容器

- 全屏页面（非 Sheet），顶部 AppBar：返回 + 标题（「新建待办」/「编辑待办」）+ `保存`（44dp）。
- 返回时有未保存改动 → 弹确认对话框（`放弃改动 / 继续编辑`）。

### 6.2 标题字段

- 20sp/700，全宽，底部 1px `separator`，上下内边距 16/12。
- 占位符「标题」。

### 6.3 折叠分组（真渐进披露）

五个分组，**顺序固定**：

```
1. 计划执行   日期 / 时段 / 时长 / 重复 / 重复开始 / 重复结束
2. 截止       截止日期
3. 提醒       提醒列表 + 添加
4. 整理       日历 / 优先级 / 标签
5. 内容       备注 / 子任务 / 附件
```

- 每组分隔：分组之间 12dp 间距，分组上下 1px `separator`。
- 分组头 48dp：标题（13sp/700，`textSecondary`）+ 摘要（13sp，`textTertiary`）+ 右侧 chevron。
- **展开规则：有值的分组默认展开；全空的分组折叠为一行摘要。**
- 摘要文案规则：计划执行 `今天 09:00 – 10:00` / `未安排`；截止 `11月9日` / `未设置`；提醒 `1 条` / `未设置`；整理 `个人 · 高优先级`；内容 `备注 · 子任务 2/5 · 附件 1`。
- 展开动画 160ms，仅旋转 chevron + 高度过渡，不做位移弹跳。

### 6.4 分组内的字段行

- 每行 48dp，左标签 15sp + 右值 15sp，行间 1px `separator`。
- 已设置的值用 accent + 600 字重；未设置用 `textSecondary`。
- 「计划执行」与「截止」**永不合并**为一个「时间」分组。
- 重复规则挂在「计划执行」下——重复的是执行计划，不是截止日。

### 6.5 二级页面

| 二级页 | 承载内容 | 返回主表单的摘要 |
|---|---|---|
| 子任务 | 列表、进度（`2 / 5 已完成`）、勾选、删除、重排、添加 | `3 条 · 2/5 已完成` |
| 附件 | 列表、缩略图、大小、添加时间、预览、分享、删除 | `2 个` |

- 二级页顶部 AppBar：返回 + 标题 + `完成`（44dp）。
- 二级页底部保留全局底部导航，不遮挡。

### 6.6 底部动作区（编辑页）

自上而下，仅三个按钮，全宽，间距 8dp：
1. `安排执行时间` —— 唯一使用 `accentSoft` 底 + accent 描边的强调按钮；仅在该待办无有效 TaskAllocation 时出现。
2. `标记完成` —— 线性按钮。
3. `移到回收站` —— 危险按钮（`error` 文字 + `errorBorder` 描边）。

### 6.7 重复系列编辑

编辑或删除重复待办时，必须弹出一个三选一 Sheet，选项文字说清影响范围：
- `仅此一次 · M月D日`
- `这一次及以后的所有重复`
- `整个系列（含已过去的）`

禁止使用「确定 / 取消」式模糊表述，禁止默认选中某一项。

## 7. 边界状态

| 状态 | 规定 |
|---|---|
| 超长标题 | 列表内最多 2 行 + 省略号；表单内可完整显示并滚动。行高自适应，最小高度兜底 60dp。 |
| 超长待办数量 | 列表虚拟滚动；分组头粘性；不提供「加载更多」按钮，改为滚动到底自动加载。 |
| 360dp 小屏 / 字体缩放 ≥1.3× | 按 §3 的下限降级。视图段文字可缩短为「今天 3 / 未安排 12 / 全部 18」单行；日期带格高降至 48dp；胶囊字号降至 12sp。不得出现文字截断成不可读或目标低于 44dp。 |
| 键盘 + Safe Area | 见 §5.6。 |
| 无网络 / 同步失败 | 列表顶部一条横幅（`errorContainer` 底，48dp 起，可两行）+ 受影响行内一个「未同步」徽标 + 横幅右侧 `重试` 动作。**不替换列表、不弹阻断对话框、不清空本地数据。** |
| 权限被拒（通知 / 存储） | 首次触发时在对应属性面板内一条内联说明 + `去设置` 动作；不做全局弹窗。 |
| 删除确认 | 单个非重复待办直接删除 + Snackbar 撤销（5s）。重复待办走 §6.7。 |
| 空状态 | 见 §4.6。 |

## 8. 动效

| 场景 | 规格 |
|---|---|
| Sheet 入场 | 220ms，`cubic-bezier(.2,.8,.2,1)`，translateY 16dp → 0 + opacity .5 → 1 |
| 遮罩淡入 | 180ms，opacity 0 → 1 |
| 分组展开 | 160ms，高度过渡 + chevron 旋转 180° |
| 视图切换 | 无转场动画，即时切换（避免把注意力放在动效上） |
| 复选框 | 无动画，即时切换 |
| Snackbar | 5s，底部居中，含 `撤销` 动作 |

禁止：共享元素过渡、视差、弹性过冲、装饰性脉冲。

## 9. 无障碍

- 所有图标按钮必须有 `contentDescription`；装饰性 SVG 标记 `aria-hidden`。
- 复选框、分段按钮、日期格暴露选中态给 TalkBack。
- 触摸目标除尺寸外，行内元素之间保留 ≥4dp 间隙，避免误触。
- 文字缩放支持到 200%：布局按 §3 与 §7 降级，不出现裁切。
- 颜色永不作为唯一信息载体：逾期同时有「逾期 N 天」文字，优先级同时有文字标签（在表单内），标签同时有名称（在表单内）。
