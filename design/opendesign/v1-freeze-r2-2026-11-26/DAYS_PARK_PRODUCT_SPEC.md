## 0. 产品判断

DaySpark 是**本地优先的个人时间管理工具**：待办与日程都是完整对象；待办可以被安排到具体时间（计划执行），但截止不是时间占用；日历同时呈现日程、计划执行和定时截止。

产品成熟度不看功能数量，而看用户能否不打断地完成十件事：

1. 快速记下一件事，不被迫填表。
2. 把一件事安排到具体时间。
3. 看清今天要面对什么。
4. 管理全部待办，而不是只看见今天。
5. 在日历上改期、改时长、建新条目。
6. 处理重复任务与提醒。
7. 找到一条很久以前的记录。
8. 改错、删除、恢复。
9. 让 AI 帮忙整理，但写入前必须确认。
10. 在多设备、离线、失败时仍然知道数据在哪。

**产品原则**

- 信息密度优先，不用大圆角、渐变和装饰性动效掩盖层级。
- 一个事实只有一个写入口：截止、计划执行、日程时间是三件事，不互相偷写。
- 失败必须保留输入，并给唯一明确的下一步。
- 读不到不等于没有数据；空态、加载态、失败态必须分开。
- 破坏性操作先说明影响范围，再执行。
- 原型中的 AI、网络、文件、通知、权限、小组件可以是模拟的，但**用户可见的流程和结果必须真实**。

## 1. 对象与术语

| 对象 | 定义 | 关键约束 |
|---|---|---|
| 待办 Todo | 一件要完成的事 | 可无日期；可有截止；当前最多一个计划执行（重新安排会替换当前计划；历史计划不在 v1）；可重复；可完成/删除/恢复 |
| 日程 Event | 一段被占用的时间 | 有开始/结束或全天；可跨日；可重复；不参与“完成” |
| 计划执行 TaskAllocation | 把待办安排到某天某时段 | 与截止独立；一个待办同时最多一个当前计划；写入日历时间轴 |
| 截止 Due | 必须完成的时间点 | 只画一条线/一个标记，不占用时间轴；可只日期或日期+时间 |
| 日历 Calendar | 事件与待办的共享分组/颜色空间 | 必有归属，不存在“未分类”；删除前必须迁移或一起删除 |
| 标签 Tag | 跨日历的横向分类 | 多选；不改变归属；删除标签不删除条目 |
| 重复 Repeat | 从计划日期或截止日期起算的规则 | 单次实例与整个系列是两个破坏面 |
| 提醒 Reminder | 锚定计划开始或截止的提醒 | 没有时间锚点时相对提醒不可用；绝对时间仍可选 |

**术语纪律**：界面只用「待办 / 日程 / 计划执行 / 截止 / 日历 / 标签」，不把领域对象名（TaskAllocation、Action、Projection）暴露给用户。

## 2. 信息架构

### 2.1 桌面

- 顶栏：今天 / 待办 / 日历；搜索；当前时间；账号。
- 今天：左侧任务区（已逾期、今天截止、无日期、今日已完成），右侧时间区（全天、现在、接下来）。
- 待办：未安排 / 全部 / 按日期三个视图，同一份数据不同切面。
- 日历：月 / 周 / 日；上一段 / 今天 / 下一段；显示日历；新建日程。
- 设置：账号、通用、日历管理、数据、AI、通知、同步、关于。
- 全局：命令框（⌘K）、详情抽屉、整页新建、计划选择器、确认框、Toast、撤销条。

### 2.2 手机

- 底部 Dock 固定四入口：今天 / 待办 / 日历 / 我的；“我的”进设置，桌面用右上角账号入口。
- 新建：底部 sheet / 整页；详情：整页编辑。
- 手势只做平台已有约定（返回、滚动），不自造隐藏手势作为唯一入口。

### 2.3 入口规则

- 任何对象都能通过：列表行、日历块、搜索结果、AI 动作、深链打开。
- 任何深链失败都有明确出口：返回今天 / 去回收站 / 重试。
- 任何弹层都能用 Esc / 遮罩 / 取消关闭；未保存改动先确认。

## 3. 功能规格

### 3.1 捕获与新建

**目标**：一句话记下，不强迫分类；需要时再展开。

- 入口：顶栏/底栏捕获条、⌘K 动作、小组件深链、日历空白时段、命令框“新建待办/日程”。
- 类型：默认待办；只有主动切换或从日历时间槽进入才是日程。
- 标题：唯一必填；空白时内联报错并聚焦；超长截断显示，详情里完整可见。
- 待办字段：截止（只日期 / 日期+时间）、计划执行（日期+起止）、重复（含自定义星期与结束条件）、提醒（含自定义偏移）、日历、优先级（无/低/中/高）、标签（可先选，也可创建后加）。
- 日程字段：时间（开始/结束/全天/跨日）、日历、地点、重复、提醒、备注。
- 自然语言建议：识别“明天下午三点”“每周五”等，只作为**建议**；用户可以移除、改类型、改时间。原型用确定性规则模拟。
- 保存前可见：所有会被写入的事实都显示在表单上；没点开的字段不写入。
- 保存：成功 toast 并回到合理位置（待办→未安排；日程→当天日历）。
- 失败：保留全部输入；显示原因；提供重试。
- 离开：有未保存内容时确认“留下 / 丢弃”；浏览器关闭提示为增强项。
- 连续捕获：保存后清空并保持焦点（桌面捕获条）。

### 3.2 今天

- 三段任务：已逾期、今天截止、无日期；已完成下沉，可展开。
- 时间区：全天条目、今天早前、现在、接下来；定时截止在时间轴上只画一条线。
- 行操作：完成/取消完成、安排时间、打开详情、右键（桌面）/ 长按（手机）菜单（改期、顺延、移动日历、加标签、复制、删除）。行本身仍可点开详情；长按不是唯一入口。
- 完成：立即视觉反馈；4 秒内可撤销；撤销条只保留最近一次。
- 空态：任务区“今天清空了”；时间区“今天没有时间安排”；两者文案不同。
- 统计：逾期/今天截止/无日期/已完成数量随任何写入实时更新。
- 读取失败：显示失败状态与重试，不画成空数据。

### 3.3 待办

- 视图：未安排（没有有效计划执行）、全部、按日期。
- 分组：今天截止、已逾期/已遗漏、之后、无截止；完成项下沉。
- 筛选：日历、标签、优先级、逾期；多条件组合；显示已应用摘要；可逐项清除/重置。
- 排序：默认按截止/优先级/创建顺序；手动排序不在 v1 范围。
- 行内操作：完成、安排、打开；多选与批量不在 v1 范围。
- 计划执行与截止同时存在时，行内分别标注，不合并成一条时间。
- 重复待办：显示“当前实例 / 已遗漏 N 次”；v1 的完成与编辑按系列粒度记录（逐实例完成状态不在 v1），删除提供实例范围。

### 3.4 日历

- 视图：月、周、日；共享选中日期与筛选。
- 月：月格显示事件、计划、定时截止；`+N` 可展开当天完整列表；点日期进入日视图。
- 周：7 列时间网格（08:00–20:00）；全天行；定时截止行；重叠并排；短事件可读。
- 日：单日时间网格；全天、定时截止、重叠；跨午夜/轴外事件不画进网格，作为跨天条目并在详情说明真实时间。
- 创建：空白时段点击 → 预填开始/结束的新建日程；时间槽 → 新建日程；`cal-new` → 整页新建。
- 编辑：拖动移动（15 分钟吸附、可跨列改日期）；拖动下缘改时长（最短 15 分钟）；重复/全天/跨天条目禁止拖拽并说明原因。
- 事件详情：时间、全天、地点、日历、重复、提醒、标签（只读）、备注；删除时可选择范围。
- 日历显示/隐藏：逐日历勾选；全选/全不选；隐藏数量提示；空日历状态。
- 日历管理：新建（名称/颜色/校验）、编辑（名称/颜色）、删除（迁移到另一个日历 / 连同内容删除 / 默认日历转移）。
- 读取失败保留旧数据（stale-error）；离线时明确标注本地数据。
- 当前时间线只出现在今天；自动滚动到当前时间为增强项。

### 3.5 详情与编辑

- 桌面详情是右侧抽屉；手机详情是整页编辑。两者字段、顺序、校验一致。
- 字段：标题、完成状态、截止、计划执行、重复、提醒、日历、优先级、标签、备注、子任务、附件。
- 只读 → 编辑：显式“编辑”进入；未保存离开需确认。
- 子任务：添加、勾选、改名、删除；进度 N/M；空态。
- 标签：多选、搜索、就地新建、颜色来自标签；空态。
- 附件：原型允许选择真实文件并记录文件名/大小；上传为模拟；可移除；失败可重试（原型模拟）。
- 重复：编辑与保存只写系列锚点，保存前必须确认“整个系列”；删除提供三档：仅这一次（只跳过该日期）、这一次及以后（截断，之前保留）、整个系列。完成按系列粒度（逐实例完成不在 v1）。
- 保存：成功 toast；失败保留输入、标红原因、可重试。
- 删除：确认框说明进入回收站；可恢复。
- 深链：刷新后仍打开同一对象；对象已删除/在回收站有明确出口。

### 3.6 选择器

统一使用设计过的选择器，不直接暴露原生控件作为唯一入口：

- 日期：42 格、周一起始、换月、今天/明天/下周今天、清除、选中态。
- 时间：开始/结束、常用时段、结束晚于开始校验。
- 重复：不重复/每天/每周/每 2 周/每月/每年；自定义星期；结束条件（永不/日期/次数）。
- 提醒：不提醒/准时/5/15/30 分钟前/1 小时/1 天；自定义 N 分钟/小时/天。
- 优先级：无/低/中/高，带排序说明。
- 日历：列表 + 就地新建；默认日历徽章。
- 标签：多选 + 搜索 + 就地新建。
- 计划：日期 + 起止 + 时长 + 重叠背景提示 + 返回原编辑态。
- 实例范围：仅这一次 / 这一次及以后 / 整个系列。
- 确认框：删除、清空、退出、移除 Key、清空对话、丢弃表单；危险按钮红色。

### 3.7 搜索与命令

- ⌘K / Ctrl+K / `/` 打开；Esc 关闭；手机全屏。
- 搜索范围：标题、备注、标签、子任务、地点、日历名。
- 结果分组：待办、日程、动作；匹配词高亮。
- 键盘：↑↓ 选中、Enter 打开、Esc 关闭。
- 动作为结果：新建待办（带查询词）、新建日程、问 AI、打开设置。
- 空查询：最近待办 + 动作；无结果：用这句话新建待办。
- 加载/失败：原型可模拟；失败不画成无结果。
- 查询语法（cal:/tag:/is:）不在 v1 范围。

### 3.8 AI

- 可选功能；关闭后入口消失。Key 只在本机保存，只显示后四位。
- 配置：服务商预设、Base URL、API Key、模型；校验并保存；失败不覆盖旧配置；移除需确认。
- 检测模型：模拟 `/models` 列表；失败可重试或手动填写。
- 对话：多轮；发送中禁用；失败显示原因并可重试；清空需确认。
- 动作：新建待办、新建日程、拆子任务、安排时间；**写入前必须确认**，确认后真实修改数据。
- 空态：未配置 / 已关闭 / 读取中 / 空对话分别处理。
- 隐私：请求直达服务商；DaySpark 服务器不参与；原型不发送真实网络请求。

### 3.9 设置与数据

- 通用：默认日历、启动页、主题（白纸/暖灰/夜间）、强调色（墨色/靛蓝/苔绿）、语言（简体中文；英文暂不提供）。
- 账号：登录、注册、错误分类（密码错误/密码太短/邮箱已注册）、提交中、加载失败、退出。
- 设备：列表、加载、空、失败、移除非本机设备。
- 日历管理：新建/编辑/删除（迁移或一起删除）。
- 标签：新建/编辑名称与颜色/删除；重名校验；删除只移除标签，不删条目。
- 回收站：恢复（保留原日历/标签/子任务）、永久删除（确认）、清空（确认）、空态。
- 导入：选择真实 .ics 文件或示例；解析后预览；选目标日历；导入中；成功/失败/跳过；报告逐条列出跳过行。
- 导出：导出全部 .ics；字段尽量完整；失败提示。
- 备份：导出 JSON；合并备份选择文件、解析、去重、显示新增数量；失败提示。
- 通知：权限状态、被拒绝的恢复路径、精确提醒、测试提醒（原型模拟）。
- 同步：服务器地址可编辑、登录、立即同步、待上传、失败原因、离线横幅、冲突逐项选择（本地/服务器/合并）、服务器拒绝详情。
- 关于：版本、许可、反馈、更新说明。
- 设置内搜索、设置改动撤销不在 v1 范围。

### 3.10 系统状态

- 加载：列表/详情/搜索/设置各自骨架。
- 空：真空 / 筛选空 / 读取失败三态分开。
- 失败：保存失败保留输入；读取失败保留旧数据（能保留时）；同步失败保留本地。
- 离线：横幅说明本地优先；恢复后自动重试。
- 冲突：逐项选择，不提供“全部保留本地”掩盖差异。
- 更新：有新版本时横幅；更新说明可打开。
- 权限：通知/文件被拒绝时给恢复路径。
- 撤销：完成、删除等操作有 4 秒撤销；跨页面不丢失。
- 多标签页并发修改、数据版本迁移不在 v1 范围。

### 3.11 小组件与外部表面

- iOS/macOS/Android 小组件是**只读快照 + 深链**；原型展示三种类型与尺寸、空态、过期、完成态。
- 小组件配置、锁屏/灵动岛不在 v1 范围。
- OAuth 同意页：允许/拒绝/凭据错误/授权失败；原型模拟。
- 反馈：复制内容、打开 GitHub；空内容禁用；复制失败有兜底。
- 更新说明：版本变化后出现一次；可从关于/横幅打开。

### 3.12 移动端

- 底部 Dock 四入口；顶部返回；安全区适配。
- 新建/详情使用整页或底部 sheet；键盘弹起时保存按钮可见。
- 日历周/月切换、日期条、筛选 sheet。
- 设置分组与返回栈；通知深链落到条目（原型模拟）。
- 横屏/平板、触觉反馈、自造手势不在 v1 范围。

### 3.13 全局质量

- 断点：<720 手机；720–1024 紧凑桌面；>1024 桌面。
- 主题：白纸/暖灰/夜间；强调色只影响操作与选中，不影响日历色。
- 焦点可见；Tab 顺序合理；Esc 关闭弹层；危险按钮默认不聚焦。
- 对比度满足正文可读；不仅靠颜色传达状态（逾期有文字/标记）。
- 日期/时间格式统一；空态/错误/成功文案不互相冒充。
- 按钮有 hover/active/disabled/loading；表单错误定位到字段。
- 浏览器兼容以 Chrome/Safari 当前版本为准；`file://` 下剪贴板/下载降级为提示。

## 4. 原型模拟边界

以下能力在 HTML 原型中**允许模拟**，但流程、状态、失败分支必须真实可见：

- AI 请求与回复（确定性脚本，不发送真实网络）。
- 同步、登录、设备、冲突（本地状态模拟）。
- 文件导入/导出/备份（真实 File API 读取 + 本地解析；不上传）。
- 附件上传（记录文件名/大小；不存二进制）。
- 通知、系统权限、精确提醒。
- 小组件快照与深链。
- OAuth 同意页。

以下能力**不允许**用模拟掩盖：

- 用户输入必须进入数据；不得写死标题、时间、日历、结果。
- 创建/编辑/完成/删除/恢复必须真实改变共享数据。
- 失败必须保留输入；不得用“已保存”掩盖失败。
- 空白/读取失败不得画成“没有数据”。

## 5. 明确不做（v1）

- 多人协作、共享日历、评论、指派。
- 插件市场、脚本系统、自定义字段。
- 自然语言大模型解析（原型用确定性规则）。
- 日历拖拽以外的手势系统（双指缩放、边缘滑动作为唯一入口）。
- 列表手动排序、批量选择、保存筛选、跨标签合并。
- 重复待办的历史实例分页与逐实例完成状态（仅保留当前实例语义）。
- 设置内搜索、数据版本迁移、多标签页并发冲突处理。
- 完整英文界面、RTL、打印样式。
- 锁屏/灵动岛、小组件配置。
- 生产级性能优化（虚拟滚动、万级数据）。

**原型 vs 正式产品的边界**：原型里的同步、登录、OAuth、AI 请求、通知、文件上传是本地模拟；这不等于正式产品不做这些能力。DaySpark 现有产品已有自托管同步、登录与 OAuth，Flutter 实现阶段按既有后端实现，不能因为原型简化而把它们列进产品不做项。

## 6. 验收场景

必须能连续完成，不出现死路、占位弹窗或固定结果：

1. 捕获“明天下午三点交报告” → 改类型/改时间 → 保存 → 在未安排看到它 → 安排到明天 15:00 → 在今天/日历看到计划块。
2. 新建待办 → 设截止（日期+时间）→ 设重复（每周一三五，10 次）→ 设提醒（45 分钟前）→ 选标签 → 保存 → 在详情看到全部字段。
3. 打开详情 → 编辑标题/备注 → 添加子任务并勾选 → 添加标签 → 选择真实附件 → 保存失败一次 → 重试成功 → 刷新后仍在。
4. 日历周视图拖动事件改期/改时长 → 打开详情确认时间 → 删除重复日程 → 选“仅这一次” → 系列保留 → 再删除整个系列。
5. 月视图点 +N → 看到当天全部条目 → 打开其中一条 → 返回月视图。
6. 日历空白时段点击 → 新建日程 → 选择日历 → 创建 → 在周/日视图出现。
7. 搜索“周报” → 高亮结果 → ↑↓ 选择 → Enter 打开 → 完成/撤销 → 搜索“无结果词” → 用这句话新建。
8. AI 问“今天还剩什么” → 回复 → 点“安排时间” → 确认写入 → 日历出现计划块。
9. 设置切主题/强调色/启动页 → 刷新后保留 → 改默认日历 → 新建待办落到新默认。
10. 导入示例 ICS → 预览 3 项 → 选目标日历 → 导入成功 → 报告显示跳过行 → 备份导出 → 修改数据 → 合并备份 → 新增数量正确。
11. 删除待办 → 回收站恢复 → 原日历/标签/子任务保留；清空回收站需确认。
12. 触发离线/同步冲突/保存失败/通知被拒 → 看到对应横幅或状态 → 按提示恢复。
13. 手机：Dock 四个入口（今天/待办/日历/我的）→ 新建待办 → 详情编辑 → 日历周/月 → 设置主题 → 返回栈正确。
14. 所有页面无“这一项没有更深的编辑步骤”式兜底；只读项明确标注为只读并可复制。
