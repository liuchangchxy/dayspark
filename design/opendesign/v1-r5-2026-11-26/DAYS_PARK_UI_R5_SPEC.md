# DaySpark R5 · UI/UX 视觉与页面契约

> 版本：R5 · 2026-11-26  
> 地位：本文定义第五轮设计优化的视觉系统、页面结构与响应式行为。产品语义以 `DAYS_PARK_PRODUCT_SPEC.md` rev.5 为准；可交互结果以 `dayspark-prototype.html` 为准。  
> 设计源：`dayspark-spec.html`（设计母版）→ `prototype/build.py` → `dayspark-prototype.html`。不另做静态设计。

---

## 1. 方向

**日光纸页 / Daylight Ledger**：左侧深墨轨道承载产品身份，内容区像一张摊开的日程纸。时间不是背景，而是主结构：今天与日历共用一条连续的日线。

- 品牌记号：日出圆点 + 光线；主强调色朱砂。
- 日程 = 实心色条 + 浅色底；计划执行 = 虚线空心框；截止 = 琥珀小旗 / 截止泳道；重复 = 循环标记。四者不共用块形。
- 不使用渐变、装饰性动画、彩色阴影或 emoji 图标。
- 普通列表不使用卡片阴影；阴影只用于抽屉、浮层、弹层。

### 2.3 空间

- 基础 4px；常用 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64。
- 页面边距：桌面 40，平板 32，手机 20。
- 任务行：桌面 56，手机 64；触控目标 ≥ 48×48。
- 圆角：输入/按钮 10，卡片 12，抽屉 16，胶囊 999。
- 内容最大宽度 1440；宽屏多余空间给时间线与检查器，不留下无意义空白。

## 3. 组件语义

| 对象 | 形状 | 规则 |
|---|---|---|
| 日程 | 浅色底 + 3px 实心色条 + 时间 | 不使用高饱和整块填充 |
| 计划执行 | 1px 虚线 + 空心方形标记 + “计划” | 可拖拽/缩放；历史段弱化 |
| 截止 | 琥珀小旗 / 独立截止泳道 | 绝不画成时间块 |
| 重复 | 循环图标 + “第 n 次” | 不再用虚线表示重复 |
| 逾期 | 红字 + 细规则线 | 不用整行红底 |
| 已执行历史 | 低对比 + 删除线 + “已执行” | 不可拖拽，仍可打开 |
| 选中 | 2px 强调左边线或浅强调底 | 不整块反转 |

状态：默认、悬停、键盘焦点、按下、禁用、加载、错误、空态。焦点环 2px 强调色；错误必须文字说明，不能只靠颜色。

## 4. 页面

### 4.1 桌面壳

- 左侧深墨轨道 232px：品牌、全局搜索、今天/待办/日历/AI 助手；底部同步状态、当前时间、账号。
- 1180px 以下轨道 208px；1100px 以下 72px 图标轨。
- 页面头：标题、范围、摘要、主操作。
- 内容滚动只发生在内容区。

### 4.2 今天

- 页面头：日期、完成/总数、计划段数、逾期、无日期、快速添加。
- “现在”带：当前日程或下一项；空闲时说明下一项。
- 主区 5/7：左侧任务分组，右侧完整日线。
- 任务分组：已逾期、今天截止、无日期、今日已完成。
- 时间区：全天、今日早前、现在、接下来；历史计划不在今天显示。
- 手机截止列表默认前三项 + “还有 N 项 · 查看全部”。

### 4.3 待办

- 默认列表；过滤全部/今天/已安排/重复/已完成。
- 行：勾选、标题、截止、安排段数、重复、标签、更多。
- 桌面选中打开 440px 抽屉；手机全屏详情。
- 批量选择与长按能力保留。

### 4.4 日历

- 桌面周视图：月/周/日切换、今天、前后、显示日历、新建日程。
- 日程、计划、截止、已执行历史各自可辨；历史默认显示但弱化。
- 旧版重复计划顶部横幅“待确认实例”；确认前不生成未来块。
- 拖拽/缩放按 `data-alloc` 身份写入；历史块不可拖拽。

### 4.5 捕获、新建、详情

- 全局快速添加：桌面 680px 命令面板，手机全屏；输入 18px。
- 保存前显示解析预览：类型、日期、时间、截止、安排、提醒。
- 新建桌面双栏；手机单栏 + 底部固定保存。
- 详情桌面 440px 抽屉，手机全屏；区块：时间、重复、提醒、计划执行、标签、子任务、备注、历史。
- 无锚点提醒显示“＋ 加绝对提醒”，能力不隐藏。

### 4.6 搜索与 AI

- 搜索为全局命令面板：待办、日程、安排、设置、操作分组。
- AI 桌面右侧 420px 面板（原型为全页），手机全屏；写入前确认。
- AI Key 只显示掩码，不落快照/备份/localStorage。

### 4.7 设置

六组：账户与同步 / 外观与日历 / 提醒与通知 / 数据与备份 / AI 与自动化 / 关于与诊断。

- 设置首页是六张任务卡片：标题、用途说明、当前状态摘要；整卡可点，进入对应分组。桌面两列，手机单列。
- 左侧分组导航与卡片入口指向同一目标，不对同一设置提供两个互相竞争的同级入口。

- 账户与同步合并：账号、同步状态、设备、冲突。
- 外观与日历：主题、默认日历、日历管理、主屏幕小组件。
- 数据与备份：标签、回收站、ICS、完整/合并备份。
- AI 与自动化：模型 Key、MCP 连接、自动化权限。
- MCP：服务状态、端点复制、读取/写入范围、客户端、最近活动、撤销。
- 原型模拟 MCP 连接，不实现真实 OAuth。

### 4.8 手机

- 底部五格：今天 / 待办 / 中央添加 / 日历 / 我的。
- 中央添加打开快速添加；日历页打开新建日程。
- 顶部 56px；内容底部留 108px；无悬浮 FAB。
- 输入 16px；底部弹层带拖拽把手；安全区适配。

### 4.9 平板

- 横屏 1024×768：72px 图标轨 + 双栏；日历周视图完整。
- 竖屏 768×1024：单栏 + 分段；详情全屏。
- 不隐藏核心入口。

### 4.10 小组件

- 设置 → 外观与日历 → 小组件进入实时画廊。
- 小/中/大尺寸；勾选完成当天实例；失败回滚；快速添加沿用解析契约。
- 版本化快照 + 类型化命令队列；不是静态截图。

## 5. 验收

- 桌面 1440×1000、平板 1024×768、手机 390×844 实际渲染。
- 浅色 / 暖灰 / 深色覆盖 Today、Todos、Calendar、Settings。
- 无小于 12px 的产品文字；手机输入 16px；无横向溢出；触控 ≥48。
- 真实操作：Today 完成/撤销、重复实例、手机截止展开、多段安排、历史安排、旧版重复、拖拽/缩放、快速添加、备份合并、AI Key 掩码、MCP 开关、小组件完成。
- 不以屏数、测试数、接线率作为验收证据；以真实打开、点击、拖拽、完成/撤销为准。
