# P3 — MCP + CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI 可操控落地（冻结需求 P0-4）——同一后端进程内嵌 MCP server：本地 Agent（Claude Code/Hermes）经 stdio 桥、ChatGPT 经远程 Streamable-HTTP + OAuth 2.1、Codex 经 stdio wrapper，统一 CRUD 日历与任务；附 `dayspark` CLI（MCP 客户端形态，顺带 dogfood）。

**Architecture:** MCP 长在 `server/` 同进程同 DB：读 = `records` 表（event/todo payload 即全量行，json_extract + rrule 扩展窗口过滤）；写 = **复用 T3 的 LWW/nextSeq/onSeqAdvanced 内部 op 通路**（AI 写入 = 一台虚拟设备的 push → 设备经 SSE/pull 自动收到）。传输双形态：`POST /mcp` 无状态 Streamable HTTP（OAuth 2.1 Bearer）+ `tool/mcp_stdio_wrapper/`（stdio↔HTTP 桥）。CLI = `tool/dayspark_cli/`，用 `/auth/login` 取 token 后**以 MCP 客户端身份**调 HTTP `/mcp`。

**Tech Stack:** Dart server（复用 shelf/drift/lww）、`rrule`（server 新增依赖，纯 Dart）、MCP 协议自实现无状态子集（initialize/ping/tools/list/tools/call/resources/list/resources/read — 若 `dart_mcp` SDK 经快速验证适配 server 端 streamable 可换用，实现者验证后报告裁定，**默认手写**）、OAuth2.1（PKCE-S256 + DCR + 轮换，复用 T2 refresh/hash 设施）

**Spec:** 主计划 P3 节（22 工具甜点区/双传输/无 delete 工具）+ 调研冻结约定（Todoist 工作流工具哲学、errors-as-tool-results、ISO 8601+IANA tz、RRULE 结构化对象）。**本计划按 P2 现实修正工具面**（calendars/tags/reminder 行尚未同步 → 工具只覆盖 event+todo，见 Task 2 冻结表）。

## Global Constraints

- 三+套绿：root `dart analyze .` 零 · `flutter test` · `cd server && dart analyze . && dart test` · `cd packages/dayspark_contracts && dart test` · 新增包各自 analyze/test 绿；禁 suppress 旗标
- MCP 硬规则：**errors 进 tool result**（`{isError:true, content:[{text:JSON.stringify({code,message,hint})}]}`，不用 JSON-RPC error 报业务错）；写工具注解 `readOnlyHint:false`（读 true）；**不提供破坏性 delete 工具**（trash = 软删可恢复，语义与回收站对齐）；日期参数 ISO 8601 + 必要处 `timezone` IANA；RRULE 一律结构化对象（freq/interval/until/byday…）不收裸字符串；`list_events` 默认 now→now+7d、窗口上限 366 天
- 版本 feature 只改 x：P2 结束 `0.22.0+24` → P3 `0.23.0+24`；**禁止 push/tag**（Phase 收尾用户确认后）
- 新增带 pubspec 的包（tool/*）会被 root `flutter analyze` 扫描 → **同步修 ci.yml test job 的依赖解析**（沿用 contracts/server 两步模式，列入 Task 7；这是 P2 首推踩过的坑，不允许复发）
- CI 一律不加 `dart format --set-exit-if-changed`、不用 `--no-fatal-infos`
- 代码风格同 CLAUDE.md；l10n 中英成对（本阶段 UI 文本极少：OAuth 同意页/CLI 输出除外——CLI 输出不做 l10n，英文即可）

### Task 2: MCP 协议端点 + 18 工具 + 3 资源（冻结表）

**Files:**
- Create: `server/lib/src/mcp/{endpoint,tools,resources,schemas}.dart`
- Modify: `server/lib/server.dart`（挂 `POST /mcp`，未认证返回 401 + `WWW-Authenticate` 指向 OAuth metadata）
- Test: `server/test/mcp_protocol_test.dart`、`mcp_tools_test.dart`

**工具冻结表（18 = 13 读 + 5 写；命名 snake_case 动词_名词）：**
读：`get_events(from,to,timezone?,limit?)`（默认 now→+7d 上限 366d，rrule 展开）· `get_event(event_id)` · `list_tasks(filter?:today|overdue|upcoming|inbox,status?,due_before?,due_after?,limit?,cursor?)` · `get_task(task_id)` · `search(query,kind?:event|task|all,limit?)` · `find_free_time(from,to,duration_minutes,timezone,working_hours_start?,working_hours_end?,working_days?)`（日历+任务忙碌段求空档，ical 风格默认工作 9-18 周一至五）· `list_trash(kind?)`（回收站可见性，只读）
写：`create_event(title,start,end,timezone?,all_day?,description?,location?,recurrence?,idempotency_key?)` · `update_event(event_id,...部分字段 PATCH 语义)` · `trash_event(event_id)`（软删=deletedAt→回收站，**非** tombstone） · `create_task(title,due?,priority?,description?,tags?,idempotency_key?)` · `update_task(task_id,...部分)` · `complete_task(task_id)` · `reopen_task(task_id)` · `snooze_task(task_id,until)`（until=ISO；落 payload 提醒字段或 completedAt 语义按 T5 payload 字段表对齐，报告写明） · `trash_task(task_id)` · `batch_create_tasks(tasks[])`（Todoist 批量哲学）
**明确不做**：`delete_*`（永久删除留给 UI 回收站）、任何 calendar/tag/reminder 工具（未同步，P2.5 后补——报告注明）
**资源（3）**：`dayspark://today`、`dayspark://overdue`、`dayspark://inbox`（list+read，返回该视图的任务/事件快照 JSON）
**注解**：读 `readOnlyHint:true`；写 false；trash 类加 `destructiveHint:true`（可恢复但删数据）
**协议子集**：`initialize`（协议版本声明，serverInfo name:`dayspark` version 取 0.23.0）、`ping`、`tools/list`（JSON Schema 全量）、`tools/call`、`resources/list`、`resources/read`；未知 method → JSON-RPC method-not-found（协议层错误≠业务错）
**errors-as-tool-results**：校验失败/未找到 → `{isError:true,...{code,message,hint}}`（hint 引导如 `list_tasks`）；hint 用 contracts 错误码风格但 MCP 层可新增 `TASK_NOT_FOUND` 等（schemas.dart 集中定义）

- [ ] TDD：协议握手测试（initialize roundtrip、未知 method）+ 每工具 ≥1 正常 + ≥1 错误路径（未找到/校验失败带 hint）+ **AI 写→设备可见** 用例（tools/call create_event 后 pull 出现该记录）→ 红→绿 → Commit `feat(server): MCP 端点与工具面`

### Task 3: OAuth 2.1 授权服务器

**Files:**
- Create: `server/lib/src/oauth/{as,middleware,consent}.dart`（`/.well-known/oauth-authorization-server`、`/.well-known/oauth-protected-resource`（MCP resource metadata）、`/oauth/register`（RFC7591 动态注册）、`/oauth/authorize`（PKCE-S256 必校、最小同意页：客户端名+scope 勾选+登录态复用 T2 session 或 email/password 一次性）、`/oauth/token`（authorization_code+PKCE、client 凭证、access 短 TTL 15min JWT 含 scope、refresh 轮换复用 T2 家族机制）、`/oauth/revoke`（RFC7009））
- Scopes：`mcp:read`、`mcp:write`（工具按注解读写校验 scope，缺 scope → tool result `FORBIDDEN_SCOPE`）
- Modify: `/mcp` 中间件：Bearer JWT 校验 + scope 门
- Test: `server/test/oauth_test.dart`（DCR→authorize 拿 code→token→调 /mcp 成功；PKCE 错码拒绝；无 Bearer 401+WWW-Authenticate；缺 scope 工具拒绝；refresh 轮换；revoke 生效）

**安全硬规则**：PKCE 只收 S256、redirect_uri 精确匹配、code 一次性 10 分钟、consent 页 CSRF、mcp 裸 bearer 不放行（Vikunja ChatGPT 踩坑已知）

- [ ] TDD 全流程 → Commit `feat(server): OAuth 2.1 授权服务器与 MCP scope 门`
