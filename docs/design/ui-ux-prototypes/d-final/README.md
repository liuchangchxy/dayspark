- **Action 不再是表格**：去掉列头与固定检查器；改为时间 · 语义图标 · 标题/条件元信息 · 状态的分组行。选中后检查器浮出，内容右缩 372px，不再遮住行尾；关闭即恢复全宽。

- **检查器按需**：只有 Action 的选中行展开；Calendar/Todo 不常驻侧栏。关闭按钮、Esc 都可收起。
- **Calendar 语义分层**：事件=浅色块 + 类别圆点；安排=白底虚线 + 空心方点；截止=独立“截止”泳道 + 虚线章，不再在时间网格里重复画线，因此不会压住事件标题。周四补上 Q4 的 16:30–17:30 安排，与检查器一致。
