# 灵光 DaySpark — 受控视觉变体 A / B / C

同一份 DOM、同一份数据、同一套布局与字阶，只改变颜色变量（冷暖 / 强调色 / 功能色用量）。
覆盖 **今天 / 待办 / 日历** × **桌面 1280×800 / 手机 390×844**，共 18 个静态画面。

## 怎么打开

直接双击 `index.html`（`file://` 可用，无任何外部网络请求、无 CDN、无外部字体）。

- **入口** `index.html`：右上切换 变体 A/B/C、平台、屏幕。
- **并排对比** `compare.html`：同一屏三版并排，可切平台与屏幕，`全部` 一次看三屏 × 三版。
- **盲选** `blind.html`：每屏只出现一次，三张缩略图随机排序（固定 seed，可复现），按 `1 / 2 / 3` 选择；`退格` 返回；结果存 `localStorage`（键 `ds-blind-v1`），可导出 JSON。
- **截图** `shots/`：18 张 2x 图；`compare-*.png` 为总览。

## 受控变量

三版共用 `app.html` / `app.js` / `app.css` / `data.js`。切换只靠根元素属性：

- `data-variant="a|b|c"` — 只选颜色变量
- `data-platform="desktop|phone"` — 平台布局（rail vs 底部导航）
- `data-screen="today|todo|calendar"` — 当前屏
- `data-view="list|detail"` — 手机上的待办详情页

`qa.mjs` 会断言：同平台同屏下，A/B/C 的 `body.innerHTML`、可见文案、以及所有行/事件/导航元素的像素矩形完全一致。

## 布局规格

- **桌面**：左侧 rail 208px；顶栏 48px（日期 / 今天 / 搜索 / 新建）；内容铺满剩余宽度。
  - 今天：时间列 56px + 分组（现在 / 接下来 / 今天截止 / 已逾期），右侧 280px「未安排」列。
  - 待办：左列表 60% + 右详情 40%；顶部筛选（未安排 / 全部 / 按日期）。
  - 日历：7 天周视图 + 小时网格 08:00–21:00（48px/小时）；事件块浅填充 + 3px 左条；计划块虚线；截止单独泳道；now line 1px。
- **手机**：顶栏 48px；底部导航 56px；内容 gutter 16px。
  - 今天：时间轴 + 分组，行高 48；未安排组预览最多 3 条；底部捕获行（不是 FAB）。
  - 待办：筛选 chip + 列表；详情整页（点行进入，左上返回）。
  - 日历：3 天视图（11/13–15）+ 小时网格；now line。

## 自测

```bash
node tools/qa.mjs     # 48 项断言
node tools/shoot.mjs  # 重跑 18 张截图 + 3 张总览
```

需要 Playwright（`npx playwright install chromium`）。`tools/pw.mjs` 会优先使用本地安装，找不到时回退到 `~/.npm/_npx` 缓存与 `~/Library/Caches/ms-playwright` 里已下载的 Chromium。

最近一次结果：`ALL PASS 48 checks`，包括

- 同 DOM / 同布局 / 同文案：6 组（2 平台 × 3 屏）× 3 版逐字节对比；
- 1440 / 1280 / 390 / 320 四档宽度、三屏均无横向溢出；
- 手机可点元素用 `elementFromPoint` 探针验证命中区 ≥48（含伪元素扩展区）；
- 对比度：正文 ≥4.5:1、次要文字 ≥3:1（逐元素实测最小值 A 3.38、B 4.59、C 3.38，均达标）；
- 盲选：6 屏各出现一次、1/2/3 键有效、进度计数正确、导出 JSON 可解析、重载后顺序可复现、选择已持久化；
- 18 张截图尺寸：手机 780×1688、桌面 2560×1600（2x）。

## 已知取舍

- **16:00 时间重叠**：周会（16:00–17:00）与周报的计划执行块（16:00–17:00）在数据上重叠，日历按两列并排呈现，标题在窄列内换行截断。
- **手机日历为 3 天视图**（规格允许日视图或 3 天视图），以便事件块可读。
- **手机未安排组**最多显示 3 条，其余需滚动或进待办；右栏计数仍为 8。
- **字体**使用系统字体栈（SF Pro / PingFang SC），不引入外部字体；非 macOS 平台字形会按系统回退。
- **compare-*.png 口径**：`compare-desktop.png` 与 `compare-phone.png` 为“今天”一屏的三版并排；`compare-all.png` 为三屏 × 三版的桌面九宫格。
- 三版都没有替用户做选择；偏好判断留给盲选与用户本人。
