# GOAL G0 v2 — DaySpark 全产品交互原型（分域并行审查版）

> 生效范围：仅 `docs/design/interaction-model/` 与 `design/interaction-model-g0` 分支。
> 基线：`5d0940d` 的现有原型。**禁止修改生产 Flutter、合并 main、启动 G2。**

---

## 0. 一句话目标

把现有原型从“功能齐全但仍有已知缺陷的初版”，推进到**视觉成立、交互完整、独立分域审查全部 P1 清零**的可交付状态，然后停下等你验收。

---

## 零、OpenDesign 是唯一设计通道（最高优先级，所有角色无例外）

- 我本人、每个 Reviewer、每个 Subagent、每一次设计判断，全部必须走 OpenDesign（MCP 服务器 `open-design`，22 个工具）。
- 开工先读 OpenDesign 中全部相关页面与历史方案；设计产出和修改必须回写 OpenDesign。
- Reviewer 必须对照 OpenDesign 原件验收，不得用 `DESIGN.md`、截图或仓库文档代替原件。
- 禁止凭个人直觉设计，禁止用本地静态稿冒充 OpenDesign 方案。
- OpenDesign 不可用 = 外部 blocker：立即停止并报告，不得静默降级。
- 本地 HTML/CSS/JS 只是"可运行载体"；设计依据必须来自 OpenDesign。

## 1. 视觉与产品基线（审美门，先于一切交互工作）

**视觉方向已冻结，不允许自创。**

- 唯一视觉真理源：仓库根 `DESIGN.md`（Direction C / D Final tokens）＋ `docs/CORE_UX_SPEC.md`。
- 允许：信息密度优先、6/8/12 圆角、细边框、单色强调、真实字阶。
- 禁止：渐变、大圆角卡片、卡片墙、装饰性阴影、AI 味插画、emoji、无意义动效。
- 必须：桌面 1440 与手机 390 都成立；中英双语都不溢出；触摸目标 ≥48dp。
- OpenDesign：唯一视觉与交互依据。本机已装 0.27.1 并接入 MCP；不可用即 blocker，不退回本地。
- 三个审美锚点页：**今天 / 待办 / 日历**。任何改动后这三页必须单独过视觉域审查。

审美门不通过，不进交互审查。

---

## 2. 交付物

1. 可直接打开、真正可操作的交互原型（本地 HTML/CSS/JS，无构建；`file://` 可用）。
2. 全量页面/入口/操作覆盖表（每条标注：沿用 / 重做 / 新增 / 有意不做 + 理由）。
3. 关键操作行为定义（创建、编辑、取消、完成、删除、恢复、失败、返回、跨页传播）。
4. 自动化真实操作测试与结果（真实点击/输入/拖动/触摸，不是 DOM 快照）。
5. 每轮分域审查记录：域、严重度、复现步骤、修复、复核结论。
6. 与当前 Flutter 的具体差异清单（给 G2–G6 用）。
7. 最终 `DAYSPARK_INTERACTION_MODEL_READY_FOR_USER_ACCEPTANCE` 或“未收敛清单”。

---

## 3. 严重度（先定义，再审查）

- **P0**：崩溃 / 白屏 / 数据丢失 / 写错记录 / 核心流程完全不可用。
- **P1**：用户可感知的错误行为——死按钮、错误跳转、状态不同步、写错日期或实例、无法返回、冻结 SPEC 明文冲突、关键控件不可达。
- **P2**：视觉细节、文案、边界情况、次要一致性。
- **P3**：吹毛求疵。

只有 P0/P1 阻断。P2/P3 记录，不阻断，不无限修。

---

## 4. 分域并行审查协议

把产品拆成 **10 个互不重叠的域**，每轮每个域派一个独立 reviewer，同时跑：

| 域 | 范围 |
|---|---|
| A 外壳 | 侧栏/底部导航/路由/返回/Esc/焦点/断点/桌面 master-detail |
| B 今天 | 投影、分区顺序、完成与撤销、全天、逾期、空态 |
| C 待办 | 日/全部/未安排/筛选/多选/排序/行内添加/计划这一天 |
| D 日历 | 月/周/日、时间格、slot sheet、拖动/缩放、凌晨折叠、回到现在、截止泳道 |
| E Composer | Quick Create/完整表单/校验/草稿/断点/各选择器/重复 |
| F 详情 | 待办/日程/实例/提醒/附件/删除恢复/窗格 |
| G 工具面 | 搜索/AI/快速添加/标签/日历管理/回收站/关于/反馈 |
| H 设置 | 通用/日历/数据/同步/AI/通知/关于，含登录态与错误态 |
| I 数据语义 | dueDate / Allocation / Event 不互替；重复实例按日解析；跨页传播 |
| J 视觉与 i18n | `DESIGN.md` 对拍、字阶/间距/圆角、中英、溢出、触摸尺寸 |

**Reviewer 规则（写进每份任务书）：**

1. 只审自己那一个域；发现别域问题记为 `cross-domain note`，交给整合者，不算自己的 P0/P1。
2. **必须先在 OpenDesign 打开本域对应设计，再操作原型逐项对照。**
3. 把原型自己的文档和测试当作**声明**，不当证据；自己写 Playwright 脚本在 `/tmp` 下跑。
3. 必须用真实指针/键盘/触摸；触摸声明用 CDP touch 验证。
4. 每条发现给：严重度、视口、步骤、观察 vs 期望、文件/行、最小复现。
5. 不许修改仓库。
6. 结束必须给一行 `DOMAIN_VERDICT: PASS` 或 `FAIL`。

**整合者（每轮 1 个，在 10 个域之后跑）：**

- 只处理跨域问题、跨页传播、以及“两个域说法冲突”。
- 不看单域细节，只验证端到端主线任务。
- 给 `INTEGRATOR_VERDICT: PASS|FAIL`。

---

## 5. 轮次与速度（防无限循环）

- **第 1 轮**：10 个域 + 整合者，全量。
- **第 2 轮起**：
  - 只有上一轮出过 P1 的域、以及被本轮修复 diff 触及的域，进深度审查；
  - 其余域只跑**固定冒烟 11 项**（启动无错、无溢出、每路由可达、无裸 i18n key）；
  - 每轮仍带 1 个整合者。
- **冻结**：某域连续一轮 `PASS` 且无 diff 触及 → 标记冻结，后续只冒烟。
- **禁止**：每轮全量重走；禁止把已冻结域重新拉回深度审查（除非 diff 触及）。

---

## 6. 收敛判据（可满足，不无限）

一轮结束记 `P1 总数`。

1. **每轮 P1 必须严格下降**。若未下降：下一轮不扩面，只对同一批域做**根因清算**（RCA），修完再验。
2. **同一 P1 连续两轮出现**：升级为根因阻塞，必须写 RCA，禁止只改表象。
3. **收口条件**（全部满足才可宣布）：
   - 所有域 `DOMAIN_VERDICT: PASS`；
   - 整合者 `INTEGRATOR_VERDICT: PASS`；
   - 全量自动化测试 100% 通过且 `skipped=0`；
   - 本域 P1 = 0 且上一轮也无新增 P1；
   - 三个审美锚点页过视觉域。
4. **硬上限 6 轮**。触顶仍不满足：停止，交付“未收敛清单”（每条带复现与根因），**禁止**宣布 READY。
5. **禁止**为了让审查通过而删除测试、放宽断言、把 P1 改判 P2。

---

## 7. 阶段

- **P0 基线修复**：先修完第十轮已知 7 条 P1（窗格滚动、窗格内子任务、重复行跨日元数据、每年重复、实例跨日绑定、多天全天、脏表单加子任务）。
- **P1 审美定稿**：三锚点页对拍 `DESIGN.md`；视觉域先过。
- **P2 交互实现**：按 `CORE_UX_SPEC` 补全所有状态；每改一处补一条真实操作测试。
- **P3 分域审查**：按 §4 并行。
- **P4 修复与定向复核**：按 §5、§6。
- **P5 交付**：产物、覆盖表、行为定义、测试结果、各轮审查记录、差异清单。

---

## 8. 红线

- 不改生产 Flutter、不合并 main、不启动 G2。
- 不把已经由 SPEC 冻结的事情丢给用户决定；只有真正与 SPEC 冲突且必须产品负责人拍板的新问题，才进最终验收清单。
- 不伪造完成；外部不可达就如实报告并给替代方案。
- 中途不把产品分歧一条条丢给用户；先比较选项、给推荐、做成可操作版本。

---

## 9. 结束语

全部满足后，报告：

`DAYSPARK_INTERACTION_MODEL_READY_FOR_USER_ACCEPTANCE`

然后停止，等待用户亲自体验与验收。未获确认前，不得声称设计已通过。
