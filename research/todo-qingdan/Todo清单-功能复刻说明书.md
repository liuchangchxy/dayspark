## 一、产品概览

WebView 内核的 macOS 待办应用，窗口标题 `Todo 清单`（中间一个半角空格）。

主窗口自上而下三块：
1. **标题栏** —— macOS 标准红黄绿交通灯，居中标题，无其它按钮
2. **主体两栏** —— 左侧栏（约 202pt 宽，浅灰底）+ 右内容区（白底）
3. **底部通栏** —— 番茄钟计时条（受番茄功能开关控制，默认关，关时无此条）

**没有全局顶栏**：刷新、账户、搜索都在侧栏里；每个页面自带页头。

**术语**：应用内把这个对象统一叫「**事件**」（快速添加栏占位符 `在此添加内容，按回车创建事件`）。
唯一例外：详情面板的 `添加子任务` 用了「任务」二字。

## 二、核心数据模型

### 分类 / 清单是一棵两层树
- **第一层 = 分类**（顶格，青色文件夹图标 + 行尾 `▸` 表示可装子项）；**第二层 = 清单**（缩进）。第三层是否存在 `?`
- 建出来是哪层，由新建对话框决定：`文件夹` tab → 恒为第一层（**该表单里没有 `归属文件夹` 字段**）；`分类清单` tab + 归属=无 → 第一层；+ 选了某文件夹 → 第二层
- 另有固定的 `未分类` 顶层条目（管理弹窗里不显示；详情面板的归属下拉里叫 `不归入`）

### 事件的字段与分流

| 字段 | 说明 |
|---|---|
| 标题 / 描述 | 描述是富文本，上限 3000 字 |
| 归属 | 挂在哪个清单下 |
| 日期 | **可为空 —— 这是分流的关键** |
| 提醒 | **只有带日期的条目才有这一行** |
| 重复规则 | **只有带日期的条目才有**（底部工具栏多一个 `⇄` 图标，共 5 个；无日期时只有 4 个） |
| 子任务 | 计数形如 `(1/20)` |
| 工作量 | `一般` / `中等难度` / `较高难度` |
| 图片 | 走系统文件选择器 |

| | 无日期 | 有日期 |
|---|---|---|
| 出现在 | **待办箱** | **日程概览**（日历） |
| 列表行左侧 | 空心圆环 `○` | 日历上是**彩色全天条**（横跨日期格、不占时段） |
| 详情面板 | 工具栏 4 个图标 | 多 `添加提醒` 行，工具栏 5 个图标 |

> 从**清单页**打开时列表行左侧是空心方框 `□`，面板标题行右侧多一个青色描边方框；从**日历**打开时该方框是红色描边。判定规则 `?`

### 标签
- **没有"新建标签"按钮**。唯一创建方式：输入框里打 `#` + 文字 + **空格**（气泡原文 `#符号后面输入文字，并以空格结尾，即可组成一个标签`）
- 跨清单存在；`所有标签` 药丸是标签面板的唯一入口；标签只有挂在事件上才存在

### 其它
- **定期计划** —— 装着可设重复规则的事件（10 种预设 + 自定义）
- **灵感** —— 只是侧栏里的一个普通分类，装普通事件
- **AI 灵感** —— 详情面板底部工具栏的模态功能，流式生成 `智能完善` / `智能拆解` 两类结果。**与「灵感」模块无关**

分类 ▾                    ← 两层树，本机 5 个文件夹：
  ├ 未分类                     小论文 / 体制内工作+考证 / 找工作 /
  ├ 小论文 ▸                   兴趣爱好 / 大论文
  ├ 体制内工作+考证 ▸
  ├ 找工作 ▸
  ├ 兴趣爱好 ▸
  ├ 大论文 ▸

  ├ 灵感
  ├ 新建
  └ 管理

  └ 所有标签 ────────────→ 标签面板

常驻部件：**详情面板**（右侧滑出）、**番茄钟**（底部条 + 独立悬浮小窗）、**设置对话框**、**AI 灵感模态**。

## 四、桌面端限制

以下功能在桌面版**点了没反应或只给引导**，完整界面只在移动端：

| 功能 | 桌面端表现 |
|---|---|
| 微信提醒绑定 | 只有 3 个开关 + 一张引导图，无二维码、无绑定页 |
| 会员购买 | 只有 `立即续费`，**无价格、无套餐、无支付页**，明示"在 APP 中开通" |
| 登录设备管理 | 点击无反应（只显示数字 `7`） |
| 密码修改 | 点击无反应（只显示 `点击修改`） |
| 注销账号 | 点击无反应 |
| 导出到本地 | **点 `导出` 无任何反馈**：无提示、无落盘文件，弹窗直接关闭 |

### 层级与树规则（本节核心）（`13` `19` `14` `15` `17` `18` `50` `83` `51` `52` `53` `21b` `16` `21`）

侧栏 `分类` 分组是一棵**最多两层**的树，行首图标即层级信号：

| 形态 | 行首图标 | 行尾 | 能装子项 |
|---|---|---|---|
| 固定项 | 灰色空心圆圈 | 无 | 否（`未分类`） |
| 文件夹 | 青色实心文件夹 | `▸`（收起）/`▾`（展开） | **能**（子项缩进显示在下面） |
| 清单（叶子） | 该条目自己的颜色实心圆点 | 无 | 否 |

- 层级：分类（第一层）→ 清单（缩进第二层）→ 任务；文件夹套文件夹（第三层）全部截图**未出现**，是否允许 `?`。
- 第一层可混放文件夹和叶子清单（`定期计划`、`灵感` 直接挂任务）。`14`/`18`/`19` 里 `兴趣爱好` 展开只有 `摄影` 一个子项；`15`/`17` 选中 `摄影`、`大论文写作` 时整行浅灰高亮、内容区显示该清单任务。
- 展开是**多开**的：`19` 中 `体制内工作+考证`、`找工作`、`兴趣爱好`、`大论文` 四个同时展开，点另一个不收起前一个。

- `未分类` 固定第一、空心圆圈、非用户创建，管理弹窗里**不出现**（`22`/`23`/`89d`）；任务详情归属下拉里叫 `不归入`。长名截断加省略号：`高级信息系统项目管…`（`19`）。

**一句话：两个 tab 决定「是不是文件夹」，`归属文件夹` 决定「建在第几层」。**

1. 选 `文件夹` tab → 建出**文件夹**，**永远在第一层**。依据：占位符 `文件夹名称`、左端文件夹图标，且**这一 tab 根本没有 `归属文件夹` 字段**（`52`/`21b` 对比 `51`），没地方选装进谁 → 只能顶层。建出后是 `小论文` 那样：青文件夹图标 + 行尾 `▸`，可再装清单。
2. 选 `分类清单` tab + `归属文件夹: 无` → 建在顶层，成为**分类**。与 `小论文`、`找工作` 平级，与 `定期计划`、`灵感` 并列，缩进 0；不装子项时行首是彩色圆点、无 `▸`。
3. 选 `分类清单` tab + `归属文件夹: 小论文`（任意文件夹）→ 建在该文件夹下，成为**清单**。缩进一级悬挂在文件夹下（`21`/`19` 的 `大论文实验`、`大论文写作`、`时间表`、`高优先级`、`低优先级`、`摄影`、`大专`、`电网`、`公考文职电网`、`初级经济师`），行首自己的颜色圆点、**行尾没有三角**（不能再往下装）。
4. 判断标准是**位置 + 形态**，不是按钮文案：第一层 = 分类（可为文件夹或叶子）；某文件夹里 = 清单；分界就在 `归属文件夹` 选 `无` 还是某文件夹名。只有 `文件夹` 有子层，`分类清单` 建出的东西**建完不能再当父节点**。
5. 反向印证：`53` 下拉只出现 5 个文件夹、不出现叶子清单 → 能"往哪装"的对象只能是文件夹；装进文件夹 = 清单，不进 = 顶层分类。

界面**没有**「建分类 / 建清单」二选一按钮；「分类」是统称，「清单」只出现在合称 `分类清单` 里，第一层条目的官方叫法 `?`。「第一层叫分类、第二层叫清单」当官方术语 `?`，但「哪一层、能不能装子项」截图可直接确认。
术语落点（照抄）：侧栏组头 `分类`、固定行 `未分类`、新建左 tab `分类清单`、右 tab `文件夹`、字段 `归属文件夹:`、管理弹窗标题 `分类清单管理`、搜索页筛选项 `所有分类`、待办箱筛选项 `显示所有分类`、任务详情归属下拉 `不归入`/`新建`。

## 附：采集方法（自己补拍时看这里）

工具在 `tools/`，macOS 辅助功能驱动，无需额外安装。窗口基准 `1051×870@255,30`（番茄条会把最小高度顶到 870，无法缩回）。

```bash
bash tools/shot.sh   <png> [延时]          # 只截图
bash tools/tap.sh    <x> <y> <png> [延时]  # 左键点击后截图
bash tools/rclick.sh <x> <y> <png> [延时]  # 右键后截图
bash tools/drag.sh   <x1> <y1> <x2> <y2> <png>   # 拖拽（松手前截图）
bash tools/float.sh  <png>                 # 截番茄钟独立悬浮小窗
bash tools/keys.sh   esc | v | type:文字    # 按键
```

**三个坑**：
1. **番茄钟悬浮窗与主窗口标题都是「Todo清单」**，是两个独立原生窗口。`appwin.sh` 已改成取**面积最大**的同名窗口；小窗要用 `float.sh`。若取错窗口，会只截到一张 131×44 的小图
2. **截图是 Retina 2x**：PNG 宽 2102px = 窗口 1051pt，屏幕坐标 = 窗口原点 + 像素÷2
3. **原生菜单展开时 osascript 会卡死**（App 进入菜单追踪态不响应 AppleEvent）。菜单期间改用 `cliclick` + `screencapture` 直出；且**第一次点击只用于关菜单**，要点两次

另：右上角会反复弹「iTerm2 正在自动操作电脑」横幅，会挡住窗口右上角，截图前等它走。
